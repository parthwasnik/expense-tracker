# 💰 Expense Tracker

A full-stack **Personal Expense Tracker** web application built using **Spring Boot** (backend) and **React** (frontend). It allows users to **add**, **view**, **update**, and **delete** expenses by ID. Clean UI and clear functionality make tracking expenses simple and efficient.

---

## 🚀 Features

- ➕ Add new expenses (amount, description, date, category)
- 🔍 Find expenses by ID
- ✏️ Update existing expense (except ID)
- ❌ Delete expense by ID
- 💡 Real-time frontend updates using REST APIs

---

## 🛠️ Tech Stack

### Backend:
- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database (or your preferred database)

### Frontend:
- React.js
- Axios
- HTML/CSS

---

## 📦 Installation & Setup

### 🧩 Backend (Spring Boot)
1. Open the backend folder in your IDE (e.g., IntelliJ or Eclipse).
2. Run the main class: `ExpenseTrackerApplication.java`
3. Backend will start at: `http://localhost:8080`
